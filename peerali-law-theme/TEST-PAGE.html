Debugging Instructions

If CSS is NOT working:

  1. Open Browser DevTools: Right-click → Inspect → Network tab
  2. Reload the page: Check if all CSS files load (200 status, no 404 errors)
  3. Check Console: Look for any JavaScript or CSS errors
  4. Verify file paths: Ensure main.css, navigation.css, footer.css exist
  5. Clear cache: Hard refresh with Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
  6. Check functions.php: Ensure wp_enqueue_style() is correct
